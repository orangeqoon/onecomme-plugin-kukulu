# kukuluLIVE コメント連携プラグイン for わんコメ

[わんコメ（OneComme）](https://onecomme.com/) に、[kukuluLIVE](https://live.erinn.biz/) のコメントを取り込むプラグインです。

コメント取得に加え、**お絵描きコメントの大画面表示＆クリック拡大**、OBS等の配信ソフトから接続された際の**自動枠取得**および**自動公開配信（ステータス2化）**にも対応しています。  
わんコメ公式推奨設計に準拠した**専用のWeb設定画面（UI）**を内包しており、ブラウザから簡単にAPIキーや各種オプションを設定できます。

---

## 主な機能

- **専用Web設定画面（公式推奨設計）**: わんコメのプラグイン一覧からワンクリックで設定UIを開き、ブラウザ上で簡単に設定可能。
- **枠一覧の自動セレクト**: わんコメ側の配信枠一覧から自動検出（手動でのID入力は不要）。
- **リアルタイム接続ステータス表示**: 接続中、正常受信中、配信枠なし、エラーなどの稼働状態を画面上で一目で把握。
- **お絵描き・画像コメント大画面表示**: kukuluLIVE特有の「お絵描きコメント（visualchat）」や画像コメントを、通常の小さなサムネイルではなく**大サイズ（最大幅650px×高さ520px）**で迫力表示！白キャンバス風カードと影付きスタイルで綺麗にレンダリングされます。
- **クリックで原寸大ポップアップ**: 表示された絵をクリックすると、ブラウザで原寸大の高解像度画像が直接開きます。
- **表示サイズの自由なカスタマイズ**: 設定画面から、お好みの画像最大幅・最大高さに自由に変更可能。
- **自動枠取得（オプション）**: 枠がまだ取られていない場合、API経由で自動的に配信ポートを取得します。
- **自動公開化（オプション）**: OBS等のプッシュ配信を検知し、「準備中（status: 1）」から自動で「配信中（status: 2）」へ切り替えます。
- **睡眠キーワードで自動枠終了（オプション）**: タイトルに「寝る」「昼寝」「Sleeping」「Nap」等のキーワードが含まれた場合に、自動でKukuluの配信枠を返上（終了）し、通常タイトルに戻るまで自動枠取得を抑止します（設定画面からON/OFF可能）。
- **ゼロ外部依存（Pure Node.js）**: 外部npmパッケージを含まず、わんコメ本体を安定して動作させます。

## 導入手順

### 1. ダウンロードと配置
1. 本リポジトリ右上の **「Code」→「Download ZIP」**（または Releases）からZIPファイルをダウンロードし、解凍します。
2. わんコメを開き、左上の **メニュー「≡」→「連携」→「プラグイン」** を開きます。
3. プラグイン一覧画面の **「フォルダを開く」** ボタンをクリックします。
   （エクスプローラーで `%APPDATA%\onecomme\plugins` が開きます）
4. 解凍したフォルダ（フォルダ名を `kukulu-live` 等にリネーム推奨）をプラグインフォルダ内に配置します。

フォルダ構成のイメージ:
```text
plugins/
  kukulu-live/
    plugin.js
    index.html
    config.sample.json
    README.md
    LICENSE
```

### 2. わんコメ側で枠を追加
1. わんコメの左側「視聴者」または「配信」一覧の **「＋」** ボタンを押して新規枠を作成します。
2. 枠の名前を **`#Kukulu`**（または `Kukulu`）にします。
3. URLには自分のkukuluLIVE固定配信ページURL（例: `https://live.erinn.biz/v/ユーザーID`）または `https://live.erinn.biz/` を入力して保存します。

### 3. 簡単Web設定画面から設定
1. わんコメの **「プラグイン」** 一覧画面を開き、**「kukuluLIVE コメント連携」** の項目にある **「設定」ボタン（歯車アイコンまたはURL）** をクリックします。
   （ブラウザで `http://localhost:11180/plugins/com.kukululive.comment-sync/index.html` が開きます）
2. 画面の指示に従って以下を入力します：
   - **Kukulu APIキー**: [kukuluLIVE 配信ヘルプ・設定ページ](https://live.erinn.biz/help.php) から取得したAPIキー
   - **わんコメ連携先枠**: プルダウンから選択（「✨ 自動検出」のままでOK）
   - **自動枠取得 / 自動公開化 / 睡眠時自動枠終了**: 必要に応じてチェック
3. **「設定を保存して接続」** をクリックすると、即座に接続が開始されます！

※従来通り `config.json` をテキストエディタで直接編集して設定することも可能です。
